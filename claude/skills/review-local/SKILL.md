---
description: Faire une revue de code
---

Il y a probablement dans ce prompt l'appel à une autre skill de revue de code propre au projet.

Nommes cette session “Revue ” + le numéro du ticket. 

J’ai déjà checkout sur la bonne branche. 

Préparons ensemble une revue de code exhaustive, minutieuse et exemplaire. 

Nous souhaitons proposer une revue de grande qualité. 

Surtout, nous souhaitons acter bienveillance et partage de connaissance. 

- Dans un premier temps vérifie qu’on soit sur la bonne branche, si non demande moi de checkout. 
- Ensuite, analyse la description de la MR, les commentaires, le ticket lui-même, et partage ton avis : la MR est-elle bien décrite ? Sa présentation semble-t-elle conforme au code proposé ?
- Ensuite, analyse puis dis-moi si tu as au moins un commentaire bloquant. 
- Puis, demande-moi si je veux lire les commentaires non bloquants. 

Les liens vers le ticket et la MR sont partagés dans le prompt.
